# 来源登记说明

本目录保存获准共享的来源索引和确认记录。已登记首批[组织与职责来源](organization-sources.md)：用户确认制度现行，员工表仅供参考；派生内容仍为草稿，尚未完成知识库正式发布。

[编制作业与技术规则来源](tooling-sources.md)登记用户确认的完整技能、双目标与grill-me方法，以及固定V8/V7技术快照；[原技能来源清单](authoring-source-snapshot.json)登记10份历史原文件和摘要。历史原文仅追溯，当前规则以主技能和会话入口为准；这些方法的采用与公司业务知识发布分别记录。

登记时记录来源名称、发布或确认主体、日期或版本、具体页码或章节、可访问位置、适用条目及共享范围。外部原件无法共享时仅登记允许公开的索引，不擅自复制原件。

用户业务确认应保留可追溯记录，不能只写“已确认”而没有对应依据。不得将口令、令牌、真实私有配置和未经授权的人员信息作为附件提交。
