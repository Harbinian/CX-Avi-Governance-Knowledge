# 知识库升级说明

本轮已准备数据库知识引用升级，供获准同事编制和续修流程时使用。使用前请同步方法库，并取得相应内部字典；具体批次以收到的manifest为准。

## 升级了什么

- 补充用友、勤哲的数据对象、字段及关联依据，覆盖生产订单、制造大纲、流转卡、工序、检验、出入库、虚拟件和项目目录等主题。
- 可以核对流程字段来自哪个系统、如何关联、依据是什么、有哪些使用限制，减少重复调查。
- 增加离线检索、来源追溯和文件完整性检查。知识是有来源的技术快照，不会自动连接或修改业务数据库。

## 怎样静默升级已有JSON

把已治理JSON交给获准使用内部字典的AI，按“保留原件、后台核对、另存新稿、集中报告”执行：

1. 对已有业务确认、能够唯一确定的字段定义和来源说明，直接补充；仅有数据库线索或存在冲突的，列入待确认，继续处理其余部分。
2. 保留原结构版本、稳定标识和业务内容。业务步骤、职责权限、审批条件及业务状态规则的改变另行确认；不按字段同名自动改名或合并。
3. JSON只使用现有合同字段，精确库表字段映射另存辅助引用记录。校验新稿并给出变更摘要；没有适用校验器时明确未验证。

升级稿另存为新修订，不能覆盖原件或自动继承原审核结果；系统导入和正式发布仍走原治理路径。本说明提供AI作业方式，尚未实现自动批量改写或系统回写功能。

可直接向AI发送：

```text
请使用已获准取得的最新版Governance-Knowledge及内部数据库字典，
对我提供的已治理JSON做静默补充。先记录原文件摘要、结构版本及知识包批次。
已有业务确认且能唯一确定的字段定义和来源说明直接补充，无需逐项询问。
保留全部稳定标识和原有业务内容，不改变步骤、职责、权限、审批或业务状态规则；
不覆盖原件，不自动迁移结构版本，不新增合同外字段，不删除或清空未知内容。
精确数据库映射另存辅助引用记录。缺证或冲突项集中列为待确认，继续其余工作。
另存新JSON，执行适用的离线校验，交付辅助引用记录、简短变更及待确认清单；
同时报告未验证项。涉及配套正文时同步受影响说明，未取得正文则列为待核对。
不连接业务库、不上传系统、不继承旧审核结果、不自动发布。
```
