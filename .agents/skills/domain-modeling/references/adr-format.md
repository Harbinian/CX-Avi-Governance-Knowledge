# 决定记录格式

沿用现有记录位置和编号；新增时查看该目录最大编号并递增。没有既定目录时按主技能指定的任务范围创建。

记录至少包括：

- 标题与稳定编号。
- 状态：新提议为`Proposed`；其他状态须有相应确认依据。
- 背景：实际问题、适用范围和关键约束。
- 方案与取舍：实际考虑过的选择及理由。
- 提议或决定：明确已确定内容、确认范围和仍待确认的部分。
- 影响：后续约束、兼容影响及必要的未决事项。
- 来源与确认：实际材料位置、确认记录和记录日期。

没有必要的章节可以合并表达，但不得省略状态或补造确认主体。会议讨论、用户认可、技术检查和公司业务批准分别记录，不用Git提交或推送替代内容确认。
