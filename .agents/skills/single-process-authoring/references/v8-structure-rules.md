# V8结构与映射入口

完整字段、枚举及引用以本库[技术快照](../../../../technical/snapshot.json)和technical/contracts为准，编制映射及旧数据边界见[当前V8合同说明](../../../../rules/process-v8-contract.md)。技术契约用于表达兼容，不赋予业务来源权威。

新建V8使用本包空白骨架生成命令；续编保留原process_ref和其他标识。V7可严格检查及显式转换版本标识，转换稿另存；真实来源归档保持不变，3001导入规范化及差异仍由用户核对。旧内容不能为通过检查而清空，不能自动降级。

没有待定值的布尔、时间及枚举先明确依据或拟议设计状态，不以默认值掩盖未知事实。问答、六维评分、容量、确认记录放在外部Markdown，不增加到JSON。
