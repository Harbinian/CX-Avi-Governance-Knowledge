# 方案访谈与文档同步

组合使用同包的[通用方案访谈](../grilling/SKILL.md)和[领域建模](../domain-modeling/SKILL.md)。实际读取两个方法文件；原生技能调用不可用时，按文件执行并记录实际路径。整个任务遵守根[工作入口](../../../AGENTS.md)。

先核对当前请求、已有决定、相关材料和成果目录，再按依赖关系组织问题。访谈中形成明确确认的术语或重要决定时，同步维护对应文档；建议、假设和待确认事项分别记录。

具体任务的术语、决定和问答保存到用户指定的任务目录。只有当前请求授权维护共享库时，才修改本库的知识、方法或决策记录；既有授权继续有效，不因每次写入重复询问。

本方法用于通用需求和方案推敲。具体单流程的首次澄清、续编事实核验及设计情景推演，仍按同包[grill-me](../grill-me/SKILL.md)和[会话规则](../../../rules/process-session-rules.md)执行；通用方案讨论不能替代这套核验，也不表示业务批准。

## 涉及流程或部署安排时的六维问题

当访谈对象是流程、办理安排或部署设计，且成果可能进入单流程编制或复核时，问题应覆盖[流程逻辑与部署质量六维](../../../rules/process-content-quality.md)的以下方面，用于取得事实、暴露假设和缺口：

- 动作拆解：谁对什么对象做什么；关键核对、处理、记录和判断动作能否分清。
- 输入输出与完成标准：需要什么材料或信息，形成什么结果，凭什么判断完成或合格。
- 数据对应关系：涉及哪些对象、字段、状态和来源；何时创建、读取或更新。
- 跨部门交接：发出与接收岗位、交付内容、接收后动作、结果及反馈去向。
- 判断与异常处理：关键条件、各结果去向、退回或异常后的恢复位置。
- 范围与前后衔接：起点、终点、包含和排除事项；范围外工作交给谁、是否接回。

这些内容是访谈提纲，不执行1—5分评价，也不形成六维自查记录。通用方案访谈不替代单流程编制的[grill-me](../grill-me/SKILL.md)、阶段检查及交付前六维自查；任务转为单流程编制时，按[单流程编制主技能](../single-process-authoring/SKILL.md)和六维规则执行评分与记录。已有材料或答复能够回答的直接复用，只问尚影响判断的缺口；不为凑维度编造业务安排。访谈对象不是流程或部署安排时，不强行套用六维。

需要追溯迁入依据或上游差异时，读取[来源与适配记录](../../../sources/grill-with-docs-import-2026-10-19.md)。当前方法可离线读取，不依赖个人全局技能或外部服务。
